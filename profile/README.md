# FEAST 👋

**FEAST** (Flexible and Expandable Automation System Technology) is an ecosystem of open-source hardware, software, tools, and documentation for rapidly creating modular devices. This could be anything from standalone instruments to complete SCADA systems.

Learn more at [feastorg.github.io](https://feastorg.github.io).

The [Anolis](https://github.com/anolishq) runtime ecosystem provides software integration for FEAST hardware, enabling device coordination, automation, and control.
